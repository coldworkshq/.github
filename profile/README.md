<h1 align="center">Coldworks</h1>

<p align="center"><em>Use AI to need less AI.</em></p>

---

**coldwork** *(v.)* — to strengthen material by working it below the
recrystallization temperature: hardening without heat.

Coldworks runs agentic workflows, and compiles the judgments they keep
repeating into deterministic software you own. Work starts hot and
probabilistic. It cools into code. What stays hot is only what genuinely needs
a mind.

**T** is the fraction of decisions still resolved by sampling a model.
Deterministic code runs at T = 0.

The bet is that agents are a brilliant way to *discover* a process and an
expensive, variable way to *run* one forever.

## Repositories

**[doug](https://github.com/coldworkshq/doug)** — risk-routed code review.
Most pull requests don't need a human; Doug works out which ones do. Three
rules: route, never block. Never write code. Publish the miss rate.

Everything else is private or not built yet.

## How we work

- **Bars are pre-registered.** A claim gets its threshold written down before
  the measurement, and the result is published against it either way.
- **Outcomes grade everything**, including our own tools.
- **A tool that never publishes its errors is a marketing claim.** One that
  does can survive being wrong.
